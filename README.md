# ROB RUN Item Highlighter

Download: soon

Category highlighter for items, colors and switches per group.

## Groups

| Group | Color | Default |
| --- | --- | --- |
| weapons | red | on |
| ammo | orange | on |
| armor | blue | on |
| medical | green | on |
| keys | violet | on |
| task | white | off |

## Limits

Range 100-600 m, name and distance tags separate, hide taken on by default.

## Install

Admin loader, start ROB RUN, INSERT, enable only what the run needs, F2 toggles.

## Troubleshooting

Labels break after patch: new build needed. Crowded rooms: range 250 and disable ammo.

Pairs well with the valuables scanner; task group stays off on story maps.

Windows 10/11, Steam, EAC.
